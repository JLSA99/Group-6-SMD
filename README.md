# Shopping Detective

Shopping Detective is an online price comparison app. You search for a product, and it checks the prices in several online stores (Amazon, El Corte Inglés and others) and shows you where it is cheapest.

## What it does

When a user searches for a product, for example "iPhone 17", the app shows:

- the product name
- an image of the product
- the online stores that sell it
- the best price found across those stores
- a link to the store with the best price

## Example

| Search | Result |
|---|---|
| iPhone 17 | Name, image, list of stores that have it, lowest price, and a link to buy it from the cheapest one |
